使用ChipCost前必读

一、 产品使用介绍

ChipCost 是一款基于 AI 大模型的芯片价格预测与竞品分析工具。输入芯片型号后，系统会并发查询得捷（DigiKey）、贸泽（Mouser）、立创商城（LCSC）的 1000pcs 阶梯报价，并结合 DeepSeek 的语义分析与底层业务系数，为您计算出最终的 "Should Cost" 推荐成本。

二、 API 额度与性能说明

网站使用过程涉及芯片代理平台、Deepseek大模型、汇率接口等多个API，受限于底层数据供应商与大模型接口的频率限制，平台每日设置了固定的全局调用额度（每日1000次）。同时，为防止接口被封禁，单次批量分析最多支持 100 个型号，且每个型号之间设置了至少 2.5 秒的请求延迟。如遇系统提示“API超限”或“未查询到”，请稍后或次日再试。

三、 免责声明

  • 数据来源：本平台展示的所有价格、参数、分类及 AI 推荐理由，均来源于第三方公开数据接口及大模型自动生成，仅供参考。
  • 准确性免责：由于汇率波动、供应商库存变化、AI幻觉等因素，本站不保证数据的绝对准确性、及时性与完整性。任何基于本数据做出的采购、交易或生产决策，由用户自行承担风险，本站不承担任何连带法律责任。
  • 服务中断免责：因不可抗力、第三方接口故障、云服务商宕机或网络攻击导致的服务不可用，本站不承担赔偿责任。
  • 使用规范：严禁使用爬虫脚本、自动化工具恶意刷取接口数据。一经发现，管理员有权直接封禁您的访问权限。

ChipCost 用户隐私政策

更新日期：2026年10月

ChipCost（以下简称“我们”或“本站”）深知个人信息对您的重要性。我们致力于保护您的个人信息及隐私安全。在使用 ChipCost 服务前，请您仔细阅读并理解本《隐私政策》。

一、 我们如何收集和使用您的信息

为了向您提供芯片成本查询服务，我们会收集以下信息：

  • 账户登录信息：本站依托 Cloudflare Access 提供邮箱验证登录服务。我们仅收集您的邮箱地址，用于验证您的访问权限及区分管理员身份，不收集密码等敏感信息。
  • 查询行为记录：当您使用“单件查询”、“替代型号”或“批量分析”功能时，我们会记录您查询的芯片型号、查询次数以及调用的 API 额度情况，用于生成本站全局的“数据统计”面板及为您提供历史查询依据。
  • 设备与日志信息：为保障网络安全及服务稳定，服务器可能自动记录您的 IP 地址、浏览器类型、访问时间等基础日志信息。

二、 我们如何使用 Cookie 和同类技术

本站仅使用必要的 Cookie（如 Cloudflare 注入的 CF_Authorization）来维持您的登录状态，保障您的操作连贯性。我们不会使用 Cookie 进行商业广告追踪。

三、 信息的存储与保护

  • 您的数据存储于 Cloudflare 提供的全球边缘网络（D1 数据库与 KV 存储）中，采用严密的行业标准加密传输（HTTPS）。
  • 我们仅将收集的信息用于优化网站性能、生成统计报表和防止恶意刷取，绝不向任何无关第三方出售或非法披露您的邮箱等个人隐私信息。

四、 第三方数据接口说明

在您查询芯片时，系统会自动将查询指令（如芯片型号）发送至得捷（DigiKey）、贸泽（Mouser）、立创商城（LCSC）以及 DeepSeek 大模型。此过程仅传输查询关键词，不包含您的个人身份信息。第三方平台的数据处理受其各自隐私政策约束。

五、 您的权利

您有权联系我们查询、更正您的相关信息。网站管理员（管理员邮箱）在后台拥有清空历史统计数据的管理权限。
